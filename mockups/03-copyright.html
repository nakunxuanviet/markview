Chosen: A + B + C

Use © 2026 VietTX5 in the status bar for a persistent, low-noise mark, © 2026 VietTX5 · MIT License in Settings → About, and the small version line in the sidebar welcome panel. The sidebar variant is the real app location, so the mark disappears as soon as a folder is open.

Keep the year in one constant so it is easy to bump each January. Avoid placing copyright in the native title bar (OS-controlled) or as a watermark over the preview, both compete with the document.

License note: this repo uses MIT, so the correct pair is “© 2026 VietTX5 · MIT License”, not “All rights reserved” (that phrase belongs to a proprietary license). The LICENSE file now names VietTX5 as the holder. If you later want “© 2026 VietTX5. All rights reserved.”, switch the project to a proprietary license and update LICENSE accordingly.
